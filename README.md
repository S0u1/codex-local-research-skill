# local-research · 本地收藏研究

**读取你的 X 书签、抖音收藏和 GitHub Star，分析收藏内容，按主题整理为本地文档；支持定时处理新增收藏。**

收藏后不再只是堆积链接：每条保留来源、内容摘要、关键观点/能力、证据和适用条件，按内容自动分类，并提供本地索引。它是运行在 Agent 中的收藏处理 Skill，不需要 Workbench。

## 核心功能

| 来源 | 读取什么 | 分析什么 |
| --- | --- | --- |
| X | 当前账号的书签 | 收藏帖正文、观点、证据和可行动想法 |
| 抖音 | 当前账号的收藏视频/图文 | 字幕或转写、图文内容、方法与案例 |
| GitHub | 当前账号点过 Star 的仓库 | 项目用途、能力、使用成本与维护情况 |

三类来源均可处理最近一批或全部已有收藏，也可定时检查新增。**主题默认从收藏内容归纳，不要求你预先指定。** 只有你主动要求时才按主题筛选。默认不搜索新选题、刷推荐流或把关注/点赞当收藏。

## 平台风险提醒

> 自动化访问抖音、X、GitHub 等平台可能触发验证码、请求限流或账号限制；违反平台规则时还可能导致账号暂停或封禁。请谨慎使用并遵守相应平台的现行规则。低频、只读或已登录均不保证不会触发限制，也不代表平台允许该访问方式。

- **抖音**：用户协议包含自动化工具接入、收集或处理内容的限制，并规定违规时可能限制功能或关闭账号。使用前核对 [抖音用户服务协议](https://www.douyin.com/agreements/?id=6773906068725565448)。
- **X**：自动化规则明确限制非 API 自动化，包括脚本操作网站，并说明可能导致永久暂停账号。参阅 [X 自动化规则](https://help.x.com/en/rules-and-policies/x-automation)。
- **GitHub**：API 有主限流和次级限流；触发限制后继续请求可能导致集成被禁用。参阅 [GitHub API 限流文档](https://docs.github.com/en/rest/using-the-rest-api/rate-limits-for-the-rest-api)。

以上来源核对日期为 2026-09-15，平台规则可能变化。Skill 会在首次在线接入与启用定时任务前提醒，优先使用平台允许的访问方式；发生验证码、异常登录、限流或账号警告时暂停对应来源、保留进度，不持续重试或绕过限制。也可使用自行获取的正文、导出或转写进行本地分析。

## 安装

将 ZIP 放到下载目录等技能扫描范围之外再解压，将其中 `local-research` 文件夹放进 Agent 的技能目录，确保目录下直接有 `SKILL.md`，而不是多嵌套一层文件夹；不要在已安装的技能目录内再解压副本，以免出现同名技能。

对于本地 Codex，可将文件夹放在用户技能目录（默认 `~/.codex/skills/local-research/`；自定义了 `CODEX_HOME` 时为其下的 `skills/local-research/`）。已有同名技能时先保留备份。随后在新会话中检查技能是否出现。其他 Agent 请按其技能加载方式导入整个文件夹；只支持提示词的工具可读取 `SKILL.md`，但也要能访问 `references/`。

## 首次使用

```text
用 $local-research 初始化，帮我连接收藏来源。
```

Agent 先介绍上述功能，再询问要连接 X、抖音还是 GitHub，可多选。之后按选择指导：

1. 选择范围：最近若干条、全部已有收藏或仅未来新增。普通整理未给数量时默认每个来源最近 20 条。
2. 明确本地保存目录，并展示在线访问风险提醒。
3. 检查选中来源的真实读取能力；缺失时指导 GitHub CLI 安装/登录，或当前宿主支持的浏览器扩展、接口连接与平台登录。
4. 实际读取收藏列表，核对账号和条目。仅打开浏览器或读到公开网页不算连接通过。
5. 整理任务从该列表取内容、分析并归档，继续完成批次。只初始化时验证少量元数据，不自动分析旧收藏；可要求“带我跑通一条”。

不要向 Agent 发送密码、token 或 cookie。仅选择抖音时不要求安装 gh；仅选择 GitHub 时不要求 Chrome 扩展。连接或转写受阻会说明具体缺口，手动导出只作为你选择的备用方案，不会冒充在线同步成功。

## 使用示例

```text
用 $local-research 整理我最近 20 条 X 书签。

用 $local-research 读取我的抖音收藏，分析最近 10 条并按内容分类。

用 $local-research 分批整理全部 GitHub Star，保留来源链接和分析报告。

用 $local-research 汇总已归档收藏中关于视频制作的结论。

用 $local-research 每天北京时间上午 9 点检查三个来源的新增收藏，只处理启用后的新增内容。
```

仅未来新增会在启用时建立观测基线，不自动回补历史。没有可靠收藏时间的平台只能保证相对观测基线的新增，不能保证精确时间边界。定时任务需宿主调度、账号连接与持久目录实际可用；无变化时安静，有新结果或需处理的故障时通知。

## 本地文件

根目录优先级：本次指定目录 → `LOCAL_RESEARCH_ROOT` → 当前用户主目录下的 `Documents/Research/`。

```text
Research/
  INDEX.md
  自动归纳的主题/
    INDEX.md
    x/日期-帖子ID/report.md
    douyin/日期-视频ID/report.md
    github/日期-owner--repo/report.md
  .state/   # 连接偏好、收藏批次、去重与进度
```

每个条目还有 sources.md 记录来源和证据范围，有字幕/转写时按需保留。历史报告不覆盖，跨主题使用索引关联，原平台收藏保持不变。文件、账号状态和收藏内容不属于技能源码，分享包不包含这些运行数据。

## 运行能力与验证范围

需要能读写本地文件并调用网络/连接工具的 Agent。本包提供执行流程，不捆绑账号、私有下载脚本、浏览器扩展或转写模型。GitHub 提供 gh 的 Star 读取命令；X/抖音按宿主实际支持且符合平台规则的接入方式准备。能否在线读取取决于连接和权限，不能承诺任意环境安装后立即采集。

当前指令与分享包经过格式、引用及场景检查，尚未在新用户机器上验证三平台完整采集。初始化必须把“列表可读”“内容可得”“分析完成”和“后台定时可运行”分别验证。详见 [初始化](references/onboarding.md)、[归档约定](references/archive.md) 和 [增量流程](references/incremental.md)。
