# local-research · 本地情报调研

一个把 GitHub 项目、抖音内容与 X 帖子/收藏整理成本地 Markdown 文档的 Agent Skill。按主题和来源归档，保留证据范围、历史版本与索引，也支持已有资料综述和增量记录。

这是交给 Agent 执行的工作流指令包，不是独立运行的爬虫或定时服务。它不依赖 Workbench 或作者的本机环境。

## 平台风险提醒

> 自动化访问抖音、X、GitHub 等平台可能触发验证码、请求限流或账号限制；违反平台规则时还可能导致账号暂停或封禁。请谨慎使用并遵守相应平台的现行规则。低频、只读或已登录均不保证不会触发限制，也不代表平台允许该访问方式。

- **抖音**：用户协议包含自动化工具接入、收集或处理内容的限制，并规定违规时可能限制功能或关闭账号。使用前核对 [抖音用户服务协议](https://www.douyin.com/agreements/?id=6773906068725565448)。
- **X**：自动化规则明确限制非 API 自动化，包括脚本操作网站，并说明可能导致永久暂停账号。参阅 [X 自动化规则](https://help.x.com/en/rules-and-policies/x-automation)。
- **GitHub**：API 有主限流和次级限流；触发限制后继续请求可能导致集成被禁用。参阅 [GitHub API 限流文档](https://docs.github.com/en/rest/using-the-rest-api/rate-limits-for-the-rest-api)。

以上来源核对日期为 2026-09-15，平台规则可能变化。Skill 会在首次在线接入与启用定时任务前提醒，优先使用平台允许的访问方式；发生验证码、异常登录、限流或账号警告时暂停对应来源、保留进度，不持续重试或绕过限制。也可使用自行获取的正文、导出或转写进行本地分析。

## 安装

将 ZIP 放到下载目录等技能扫描范围之外再解压，将其中 `local-research` 文件夹放进 Agent 的技能目录，确保目录下直接有 `SKILL.md`，而不是多嵌套一层文件夹；不要在已安装的技能目录内再解压副本，以免出现同名技能。

对于本地 Codex，可将文件夹放在用户技能目录（默认 `~/.codex/skills/local-research/`；自定义了 `CODEX_HOME` 时为其下的 `skills/local-research/`）。已有同名技能时先保留备份。随后在新会话中检查技能是否出现。其他 Agent 请按其技能加载方式导入整个文件夹；只支持提示词的工具可读取 `SKILL.md`，但也要能访问 `references/`。

## 首次使用：让 Agent 带你准备

```text
用 $local-research 初始化。我想调研抖音里的 AI 视频制作工作流，请检查我需要准备什么，带我跑通第一条。
```

Agent 会先检查现有能力，再只指导本次缺少的步骤：

1. 明确来源、任务模式和保存目录；抖音搜索/推荐流询问关注主题，指定链接或收藏整理不强制问。
2. GitHub 选择 CLI 路径时检查 gh 及账号认证，并给出适用系统的安装方法和浏览器登录步骤；公开仓库可直接读网页。
3. 检查浏览器连接。需要扩展时依据你的 Agent 官方说明给准确安装链接与配对步骤，再验证抖音/X 登录与收藏页。
4. 视频需要口播分析时检查字幕或转写能力，按缺失项指导准备。
5. 用你指定的一个真实条目验证读取、分析、保存和索引；已有明确任务会继续完成，不停在初始化。

登录操作由你在浏览器或终端完成，不要把密码、token 或 cookie 发给 Agent。准备偏好保存在归档目录 `.state/profile.json`，不会随技能分享；换账号或环境后重新验证相关能力。完整流程见 [初始化与准备](references/onboarding.md)。

## 使用

```text
用 $local-research 调研 https://github.com/owner/repo，保存到本地。

用 $local-research 分析这些 X 帖子，按“开发工具”主题归档。

用 $local-research 分析我提供的视频转写，保存到 ./research。

用 $local-research 对已有 AI 工具报告做比较，输出英文报告。
```

将示例链接替换为实际研究对象。`$local-research` 是 Codex 调用形式，其他宿主使用其支持的调用方式。

输出根目录优先级：本次指定目录 → `LOCAL_RESEARCH_ROOT` 环境变量 → 当前用户主目录下的 `Documents/Research/`。环境变量是供 Agent 读取的约定，不需要额外配置程序。

```text
Research/
  INDEX.md
  开发工具/
    INDEX.md
    github/日期-owner--repo/report.md
    github/日期-owner--repo/sources.md
    x/日期-帖子ID/report.md
    digests/日期-主题/report.md
```

抖音条目保存在主题下的 `douyin/`。证据文件按需保存；`.state/` 按需保存初始化偏好和本地增量状态，`.staging/` 放工具中间产物。仅采集可只产出 sources.md。详细约定见 [归档规则](references/archive.md)。

## 定时调研

```text
用 $local-research 每天北京时间上午 9 点检查我的 GitHub Star 新增，分析并归档；只处理启用后的新增内容。

用 $local-research 每周一北京时间上午 9 点搜索抖音的 AI 游戏美术教程，最多分析 5 条新内容，归档到我已配置的目录。
```

Agent 会检查宿主调度能力、运行时的浏览器/账号访问及持久目录，补齐周期与时区等缺失信息，再创建或更新任务。调度成功前不会声称已开启；没有调度能力时可手动执行同一流程。无变化时保持安静，有新结果、故障或需要操作时通知。机器休眠、登录过期或后台无法连接浏览器时，任务可能无法采集，应按实际错误恢复。

## 能力与依赖

| 场景 | 需要的能力 | 缺失时 |
| --- | --- | --- |
| 分析本地原文、字幕、旧报告 | Agent 能读取和写入本地文件 | 无文件写入能力则不能完成归档 |
| GitHub 当前项目调研 | 网络读取或只读 API；gh 可选 | 分析提供的材料，注明无法确认当前状态 |
| 抖音 / X 在线收藏 | 平台支持的只读接口，或 Agent 可操作的已登录浏览器 | 使用用户提供的导出或正文 |
| 视频口播分析 | 字幕/转写，或用户已配置的转写工具 | 保存元数据和缺口，不伪造完整分析 |
| 定时增量 | 宿主提供调度工具且用户授权 | 手动运行 |

没有捆绑平台账号、下载脚本、浏览器插件、语音模型或云端密钥。平台界面和访问能力可能变化，工作流要求核实实际页面与工具，不保证无人值守全量采集。

## 数据与共享

默认仅写选定本地归档目录，不自动向知识库发布、不修改平台收藏。联网访问仍由所选工具完成，模型和工具的数据处理方式由使用者的运行环境决定。调研文档、登录数据和收藏记录不属于技能源码，分享技能时不要把个人归档打包进去。
