# 抖音采集与分析

## 选择范围

指定链接只处理指定项。收藏页使用已登录 Chrome，在 `https://www.douyin.com/user/self?from_tab_name=main&showTab=favorite_collection` 确认“收藏 → 视频”；未给范围默认可见一屏，不能声称全量。推荐流“刷几条”默认最多 10 条，兴趣参考 AI、自媒体、商业、游戏制作，以用户当前主题优先。

主题搜索先提炼核心信号、纳入与排除范围。默认目标 10 条相关结果，最多检查目标三倍候选或 15 分钟；数量指有效相关结果。最多两次保留原意的查询细化，记录实际查询，不扩大主题凑数。

通过当前 Chrome 工具文档读取实际可见卡片，核实数字 ID、URL、标题、作者、说明和可见时长。推荐流切换后核实活动 ID 变化再计数。登录失效、验证码、重复结果或连续三次无新条目时停止并记录缺口。

## 筛选与内容获取

主题相关度 0–5：4–5 明确有方法、案例或证据，优先处理；3 部分相关或需核实，列待查；0–2 只有关键词或无关则跳过。缺乏描述的品牌宣传不能仅凭账号名接受。推荐流判断相关性、信息密度、可行动性和证据，而非关键词。

保存本批候选清单（ID、URL、标题、作者、查询、相关度、处理决定、理由和采集时间）到本次归档目录。抖音 note 图文不要送视频下载器；通过浏览器读取实际文字和图片，只有元数据则记 collected，关键图片未读则记 partial，不能伪装成已分析视频。

已有转写可只读复用。视频需要下载转写时，可以复用现有独立工具：

```bash
python3 /Users/drew/.codex/skills/douyin-favorites-sync/scripts/sync_favorites.py \
  --items-file '<absolute-manifest.json>' \
  --output '<root>/.staging/douyin/<batch-id>'
```

manifest 为 `{"items":[{"video_id":"实际ID","url":"核实过的URL","title":"标题","author":"作者","description":"实际说明"}]}`。以上路径占位符必须替换为实际绝对路径。运行前确认脚本存在并检查参数与写入范围；始终明确 --output，绝不使用旧收藏库默认目录。本地 WhisperX 默认 small/中文/CPU/int8，依赖不存在时说明阻塞；仅用户明确选择云转写时启用云端。

此工具只负责采集，不代表分析完成。核对返回 ID 与请求一致，再把本次所需 metadata、transcript.txt、transcript.srt 及媒体证据复制到 archive.md 对应条目目录，sources.md 记录中间位置。保留恢复材料；不要迁移旧库或运行旧 Workbench/feed 队列。恢复时复用已有中间产物和转写，不因工具 seen 状态跳过分析。

## 分析

读取真实转写与元数据，按需读 SRT 或观看关键画面。无转写不能编造口播；ASR 修正注明不是逐字原话，视觉观察记录时间和实际可见内容。

报告按内容类型（访谈、教程、案例、观点、测评）组织：简要摘要、核心主张、钩子与结构、证据与例子、可行动想法、不确定性。长材料补主题或步骤详解，保留具体工具、参数、数字、人物和案例；有时间戳时附引用。标题无需兼容旧看板解析器。

只有材料支持新机会时写产品方向：用户、场景、最小形态、时机证据与最低成本验证。延伸分析区分作者观点与自己的判断，锚定具体材料。短推广保持短，不强凑章节和篇幅。

画面理解使用本次可用且授权的能力，不自动投递旧 Windows 共享视觉队列。所需视觉缺失时记录 partial；不等待不存在的后台任务。报告候选、重复、跳过、实际采集/转写/分析和失败的数量，以及本地文件链接。
